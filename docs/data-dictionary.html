Manger / Data dictionary

Database dictionary and constraints

Exact columns, nullability, defaults, relationships, indexes, and migrations.

Column types, defaults, nullability, keys, and indexes below were extracted by applying the actual migration functions to an isolated SQLite database. The migration ledger is created separately by the CLI runner. SQLite affinity is not strict typing: only explicitly declared checks provide stronger guarantees.

Connection and persistence policy

app/database/connection.php sets foreign_keys = ON, busy_timeout = 5000, PDO exception mode, and associative default fetch mode. The database lives at storage/database.sqlite. There is no configured WAL pragma, encryption layer, backup scheduler, or migration rollback command.

The ledger migrations has no migration application timestamp. The internal SQLite sqlite_sequence table is an engine artifact of AUTOINCREMENT, not an application entity.
