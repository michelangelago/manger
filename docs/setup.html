Manger / Getting started

Install and run Manger

Requirements, configuration, startup, and terminal commands.

Quick start

Requirements

  • PHP 8.2 or newer, with PDO and pdo_sqlite enabled.
  • Composer.
  • A Telegram bot token from BotFather.

Install and run

bash
composer install
cp .env.example .env

Set TELEGRAM_BOT_TOKEN in .env, then run:

bash
composer migrate
composer bot

In Telegram, send /start to register. Type / to open the command menu or send /help for the full syntax. Stop the bot with Ctrl+C.

Migrations create the database and seed six food groups: fruits, vegetables, grains, protein, dairy, and fats.

Configuration

The bot loads configuration from the root .env file.

VariablePurposeDefault
TELEGRAM_BOT_TOKENToken provided by BotFather; required to start the bot.None
APP_TIMEZONETimezone used for daily logs and calendar summaries.America/Recife

Example:

dotenv
TELEGRAM_BOT_TOKEN=your_bot_token
APP_TIMEZONE=America/Recife

On startup, the bot synchronizes its Telegram autocomplete menu. The menu lists command names; descriptions and /help explain their arguments and flags.

Composer commands

CommandPurpose
composer botSynchronize the Telegram menu and start long polling.
composer migrateApply pending migrations and seeds.
composer testRun all automated tests.
composer startServe the optional web status page at http://localhost:8000.

The web status page is separate from the Telegram bot. Stop either process with Ctrl+C.

Reading the HTML documentation

Open docs/index.html directly in a browser. All pages use relative links and local styles, with no external dependencies. You can also serve the documentation separately:

bash
php -S 127.0.0.1:8080 -t docs

Visit http://127.0.0.1:8080. The documentation server is separate from composer start, which serves only the web status page.

Troubleshooting

SymptomCheck
Bot asks for a token at startupSet TELEGRAM_BOT_TOKEN in the root .env file.
SQLite reports a missing driverEnable PHP PDO and pdo_sqlite for the CLI PHP executable.
A table or column is missingRun composer migrate before restarting the bot.
A food or group is not foundCreate it first and quote names containing spaces.
A personal command asks for registrationSend /start from the same Telegram account.
New commands do not appearRestart composer bot to synchronize the Telegram menu.
Dates appear under an unexpected dayCheck APP_TIMEZONE and restart the bot after changing .env.
