Manger / Commands

Telegram command reference

Every command, operation flag, input format, and compact view.

Operation flags

Flags ignore letter case. Commands support only the operations listed below.

FlagOperation
-IIndex / list
-CCreate
-RRead
-UUpdate
-DDelete

/dview has its own period flags: its -D means day.

Registration and help

CommandResult
/startRegisters your Telegram ID and full name, then shows your saved details.
/helpLists available commands and their syntax.

Sending /start again welcomes you back and updates your name without creating a duplicate user.

Food groups — /fgroup

text
/fgroup -I
/fgroup -C "Whole grains"
/fgroup -R "Whole grains"
/fgroup -U "Whole grains" "Cereal grains"
/fgroup -D "Cereal grains"

Index also shows the available operations. Duplicate names are rejected. Groups referenced by foods cannot be deleted.

Food catalog — /food

text
/food -I
/food -C "Green apple" 52 fruits
/food -R "Green apple"
/food -U "Green apple" "Apple yogurt" 90 dairy
/food -D "Apple yogurt"

Create takes a name, calories per 100 g, and an existing group name. Calories must be a non-negative integer. The bot resolves the group's name to its database ID internally.

Update takes the existing food name followed by the new name, calories, and group name. Duplicate food names are rejected. Foods referenced by consumption entries cannot be deleted. Index also shows the available operations.

Log consumption — /eat and /dfoods

Quick logging:

text
/eat "Green apple" 150

This is a shortcut for /dfoods -C "Green apple" 150 and uses the same validation and automatic daily log creation.

Full operations:

text
/dfoods -I
/dfoods -C "Green apple" 150
/dfoods -R 1
/dfoods -U 1 "Green apple" 200
/dfoods -D 1

Register with /start first. Food names must exist in the catalog, and quantities must be positive whole grams. Read, Update, and Delete use the entry ID shown in the reply, because the same food can be logged more than once.

Daily logs — /daily

text
/daily -I
/daily -R
/daily -R 2026-11-13

Only Index and Read are available. Read shows the day's food entries and total calories. Omit the date to use today in APP_TIMEZONE.

Calorie summaries — /dview

text
/dview
/dview "2026-11-13"
/dview -D 2026-11-13
/dview -W
/dview -M 2026-11-13
/dview -Y
FlagPeriod containing the selected date
-DDay; the default.
-WCalendar week, Monday through Sunday.
-MCalendar month.
-YCalendar year.

The date defaults to today in APP_TIMEZONE. A date and flag can appear in either order.

Summaries show total calories first, then combined grams and calories per food. Repeated foods are merged. Up to 15 foods are shown, ordered by calories; the footer counts additional foods, which are still included in the total. Empty periods show zero calories.

Browse foods by group — /gview

text
/gview
/gview "fruits"

View the entire catalog or one group. Foods appear alphabetically under their group, with a compact name and calorie value beneath a kcal/100 g heading. Empty groups are marked as empty. Large catalogs are split into short messages, and long names are shortened for display.

Daily calorie goals — /goal

text
/goal -C 2000
/goal -R
/goal -U 1800
/goal -D

Register with /start first. Each user has one goal, expressed as a positive whole number in kcal/day. Create refuses to overwrite an existing goal; use Update to change it.

Today's /dview shows the goal and remaining calories, or calories over the goal. Goals are current settings without historical versions, so this comparison is omitted for past dates and weekly, monthly, and yearly summaries. Deleting a goal does not remove food entries.
